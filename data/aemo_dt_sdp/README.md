# SDP-teacher trajectories

Training corpora for the shipped physics-v2 Stage C Decision Transformer. Most files here are ignored by Git; the public shipped corpus is hosted on Hugging Face.

## Current shipped corpus

- `dt_trajectories_jtsoc_v2cal_conservative.parquet`: 320 episodes, 3.13M rows, `rtg_value = -J_t(soc)`, generated with `--deg-calibration 0.12 --rtg-mode j_t_soc`.
- Public copy: [mrvictoru/AEMO_simulated_trade_sdp](https://huggingface.co/datasets/mrvictoru/AEMO_simulated_trade_sdp), SHA-256 `14c94ab9c7aa7db3e9a55cf8e245cbb72ab10c9f2666403e4917801eee3cf883`.
- Generated by [scripts/generate_sdp_dt_trajectories.py](../../scripts/generate_sdp_dt_trajectories.py) using the honest SDP executor in [src/aemo_sdp_executor.py](../../src/aemo_sdp_executor.py).

The checkpoint sidecar `return_scale=23,284.83` is authoritative for inference; recomputing the auto-scale from this corpus gives approximately 21,067–21,193. See [the reproduction guide](../../docs/reproduction.md) and [provenance R3](../../paper/audit/provenance.tsv).

## Historical corpora

- `dt_trajectories_jtsoc_combined.parquet`: 640-episode v1 combined corpus.
- `dt_trajectories_full.parquet` and `dt_trajectories_aggressive.parquet`: earlier Stage B corpora.
- `dt_trajectories_jtsoc_v2_conservative.parquet`: superseded and removed publicly; do not substitute it for the v2cal corpus.
