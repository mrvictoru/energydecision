# Historical FCAS-rich corpus

`aemo_fcas_dataset.parquet` is a historical behaviour-cloning corpus: 2,425 episodes, 78.4M rows, about 3.1 GB. It is **not** the shipped Stage C DT training corpus; the shipped policy uses SDP-teacher trajectories under [aemo_dt_sdp](../aemo_dt_sdp/README.md).

## Contents

- PPO: 905 episodes
- TD3, A2C, DDPG, SAC: 300 episodes each
- FCAS rule: 300 episodes
- Old rule: 20 episodes
- Three horizons (12-day, 8-week, 26-week), five regions, three battery sizes with medium bias
- [autoresearch_pilot/](autoresearch_pilot/README.md): 8 train + 4 validation episodes, rebuilt with `scripts/build_aemo_fcas_pilot_spec.py --build-pilot`

Generated by [scripts/generate_fcas_dataset.py](../../scripts/generate_fcas_dataset.py). Fetch regional AEMO data first with `scripts/fetch_aemo_region.py` inside Distrobox. Entry-point scripts live under `scripts/`, not `src/`.
