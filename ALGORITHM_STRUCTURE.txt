HOW TO USE
==========

OLD WAY (still works for backward compatibility):
  agent = Agent(env, algorithm='sdp')
  action = agent.choose_action(obs)

NEW WAY (under the hood, Agent now uses):
  sdp_solver = SDPSolver(env, horizon, ...)
  policy_table = sdp_solver.solve(forecasts)
  action = extract_action_from_policy(policy_table, current_soc)
